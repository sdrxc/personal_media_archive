# 🎬🎵 Personal Media Archive

A curated archive of movies, TV series, anime, short films, and Spotify listening history.

This repository serves as a personal media database that combines entertainment consumption, cultural exploration, and music discovery into a structured and searchable collection. It is designed to preserve viewing and listening records while enabling future analytics, visualizations, metadata enrichment, and recommendation systems.

---

## 📖 About

This repository contains a collection of:

* 🎥 Movies
* 📺 TV Series
* 🎌 Anime
* 🎞️ Short Films
* 🎵 Spotify Listening History

The collection spans multiple countries, languages, genres, and formats, ranging from mainstream blockbusters to independent, arthouse, and festival-acclaimed works.
